# Frontend integration

`api.js` — Avtodrom backend bilan bog‘lanish uchun umumiy API klient.

Backend URLni ishga tushirishda:

```html
<script>window.AVTODROM_API = 'https://YOUR-BACKEND-DOMAIN/api';</script>
```

Keyin `api.js` orqali login, START, FINISH, Dashboard, hisobot va sozlamalar serverga yuboriladi.

Eski frontend repositoryga tegilmaydi. Bu alohida yangi loyiha.
