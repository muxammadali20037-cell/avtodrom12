# AVTODROM12

Avtodrom boshqaruv tizimi uchun backend infratuzilmasi.

## Maqsad
- Avtomobil START/FINISH sessiyalarini serverda saqlash
- Soatlik tarifni bazadan boshqarish
- Faol avtomobillarni real vaqtda ko‘rsatish
- Kunlik/oylik/yillik statistika
- Login va foydalanuvchi boshqaruvi

## Arxitektura
Frontend → REST API → PostgreSQL

## Keyingi bosqich
Backend API, database schema, authentication va frontend integratsiyasi alohida commitlarda qo‘shiladi.
